# Lab 3

## Описание

Управление дочерними процессами сигналами `SIGUSR1`/`SIGUSR2` и сбор статистики в дочерних процессах по таймеру.

## Сборка

```sh
make
make MODE=release
```

## Запуск

```sh
./build/debug/parent
```

или

```sh
./build/release/parent
```

## Управление

- `+` — создать дочерний процесс
- `-` — удалить последний дочерний процесс
- `t` — включить/выключить вывод выбранного дочернего процесса
- `l` — показать список процессов
- `k` — удалить все дочерние процессы
- `q` — завершить программу
