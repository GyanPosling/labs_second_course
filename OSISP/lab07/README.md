# Lab 7

## Описание

Конкурентный доступ к файлу фиксированных записей с блокировками чтения/записи через `fcntl`.

## Сборка

```sh
make
make MODE=release
make clean
```

## Запуск

```sh
cd build/debug
./gen 10
./records_work
```

## Команды

- `lst` — показать все записи
- `get N` — загрузить запись `N`
- `mod` — изменить запись в рабочей области
- `put` — сохранить запись
- `inf` — показать версии записи
- `q` — выйти
