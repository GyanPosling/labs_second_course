# Lab 4

## Описание

Задача «производители-потребители» для процессов: общая очередь сообщений в разделяемой памяти, синхронизация через семафоры System V.

## Сборка

```sh
make
make MODE=release
make clean
```

## Запуск

```sh
./build/debug/semaphores
```

или

```sh
./build/release/semaphores
```

## Управление

- `p` или `1` — добавить producer
- `o` или `2` — удалить producer
- `c` или `3` — добавить consumer
- `x` или `4` — удалить consumer
- `s` или `5` — показать состояние
- `q` или `0` — завершить программу
