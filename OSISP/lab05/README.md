# Lab 5

## Описание

Два режима задачи «производители-потребители» для потоков:

- **5.1** — POSIX-семафоры + mutex
- **5.2** — condition variables + mutex

Поддерживается изменение размера очереди (`+`/`-`) с приоритетом shrink-запросов.

## Сборка

```sh
make
make MODE=release
make clean
```

## Запуск

```sh
./build/debug/semaphores
```

или

```sh
./build/release/semaphores
```

## Управление

- `1` — режим 5.1
- `2` — режим 5.2
- `p` / `P` — добавить / удалить producer
- `c` / `C` — добавить / удалить consumer
- `+` / `-` — увеличить / уменьшить очередь
- `s` — показать состояние
- `q` — выйти
